# MRI Anomaly Detection Project

This project performs anomaly detection on brain MRI images using image processing and statistical analysis techniques.
The DicomnormalBrain folder has normal brain scans to compare with the the images contained in the MS brain scan images of a patient with multiple sclerosis or you can use other brain scans to detect anomalies.

## Libraries Used

- `joblib` – For saving and loading models efficiently  
- `numpy` – Numerical operations and array handling  
- `opencv-python` – Image processing and manipulation  
- `pydicom` – Reading and working with DICOM medical image files  
- `scikit-learn` – Machine learning utilities and evaluation metrics  
- `scipy` – Scientific computing and statistical operations
